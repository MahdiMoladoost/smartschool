پچ افتخارآفرینان - نمایش فقط داده‌های پنل مدیر

روش نصب:
1) این فایل zip را داخل ریشه پروژه smartschool باز کنید.
2) فایل‌های هم‌نام را Replace کنید.
3) سرور Node.js را یک بار Restart کنید.
4) مرورگر را با Ctrl + F5 رفرش کنید.

تغییرات:
- همه داده‌ها و آمارهای نمونه/فیک از صفحات افتخارآفرینان حذف شد.
- صفحات افتخارآفرینان فقط داده‌های API /api/v1/homepage/honors را نمایش می‌دهند.
- API عمومی فقط رکوردهای فعال و دارای student_id را می‌خواند؛ یعنی رکوردهایی که از پنل مدیر و برای دانش‌آموز واقعی ثبت شده‌اند.
- ورود خودکار داده از HTMLهای قدیمی به جدول student_honors غیرفعال شد.
- رکوردهای auto-import شده قدیمی که student_id و created_by ندارند، هنگام خواندن افتخارآفرینان پاک می‌شوند.
- ظاهر کارت‌ها به نسخه شیک و حرفه‌ای جدید تبدیل شد.
