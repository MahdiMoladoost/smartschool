پچ اصلاح هدر/ناوبری/فوتر مشترک - نسخه ۲

این پچ مشکل نمایش لحظه‌ای هدر/فوتر قدیمی قبل از اجرای اسکریپت را رفع می‌کند.

تغییرات اصلی:
1) بخش‌های قدیمی top-bar، header/nav-container، mobile menu و footer از HTML صفحات عمومی حذف شدند.
2) صفحات فقط به فایل مشترک public/assets/js/shared-home-layout.js?v=shared-layout-02 وصل شده‌اند.
3) فایل shared-home-layout.js idempotent شد؛ یعنی اگر دوباره اجرا شود، هدر و فوتر مشترک را حذف و دوباره اضافه نمی‌کند.
4) خطای CSS صفحه olampiad.html مربوط به speak: never حذف شد.
5) کدهای قدیمی صفحه olampiad که فوترهای دیگر را مخفی/حذف می‌کردند حذف شدند تا فوتر مشترک مخفی نشود.
6) اسکریپت صفحه school-website.html برای نبودن nav قدیمی guard شد تا خطای JS ندهد.

روش استفاده:
فایل‌های داخل این zip را در ریشه پروژه smartschool کپی کنید و گزینه Replace را بزنید.
بعد مرورگر را با Ctrl+F5 یا Hard Refresh تازه‌سازی کنید تا نسخه جدید JS و CSS از کش قدیمی خوانده نشود.
